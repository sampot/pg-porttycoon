# 藍港大亨 (`pg-porttycoon`)

航線、倉儲、合約與 AI 對手 — 十二季港口經營小品。

## 遊玩

純 HTML／CSS／JavaScript（無 build）。本機開 `index.html` 或經 Playgrounds／go 安裝。

- 點**碼頭格**擴建倉儲
- 點**外海目的地**開闢／升級／派船
- 點**合約卡**承接，季末自動交貨
- **結算本季**推進時間；對手 AI 同步成長

## 開發

```bash
npx vitest run
```

遊戲開發規則見 Playgrounds [`PG-GAME-AGENT-GUIDE.md`](https://github.com/sampot/playgrounds/blob/main/docs/PG-GAME-AGENT-GUIDE.md)。
